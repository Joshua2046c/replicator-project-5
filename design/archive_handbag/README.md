# 三层书本造型手提包

当前build305。按2026-09-24本轮标注：金属半截扣舌改在框底中央，竖向伸出且高于框面；顶部绑带圆弧隆起向前平顺过渡；主体十二条大边区域小倒角。八底方桩、无侧锁和无长定位槽保持；不擅自添加防脱螺丝或支臂。

## 用户要求与当前结构
蓝绿前板一体、无内胆，前后板方孔与底板方桩插合，侧面书页板自上滑入、前上角圆弧避让；直接翻盖，上盖两端一体。棕色带分段贴面嵌槽，不跨开口或转轴；扣框无中心方块，底边有凸起金属舌。顶带隆起非提手。侧面顶部转环供用户自装肩带。
原标称220×120×190mm保留；外凸铰链造成122.3mm深度例外已有用户“这部分不改了”答复。本次明确要求的局部装饰凸起另占空间，采用披露默认尺寸：含扣舌、顶带和铰链、不含挂环220×124.237×193mm；当前姿态含五金238×124.237×210mm。不是把193mm误称为190，也不缩小包体容纳装饰。

## 承载限制——不是可直接提携的成品
2kg内容物加自重目标保持。直插方桩/方孔和可滑出侧板没有可靠抗拔连接，底板可能脱出、侧板可能被挂环提起。磁铁、装饰胶、扣舌、顶带均不作为承载件。build297独立审查已报告底板无保持为P0，本次外观修改不解决或豁免它。无螺丝保持方式尚未决定，实用提携前必须解决并实测；当前仅可外观和几何试装，不擅自加回螺钉或默认为永久胶粘。

## Making and assembly
原型PETG，建议0.2mm层高。先做方桩/方孔、铰孔、0.6mm弧缝、侧导槽、磁铁槽及贴带凹槽样片。旧长底舌/槽、AF7.4螺母座、L臂及侧锁沉孔均删除，不再制作对应样片或安排其支撑。底板底面平放、方桩向上；侧板大面平放；前后板和盖按外观/受力方向选择支撑，保护方孔和弧形导向面。盖铰筒、小磁铁座、前导槽内唇需评估悬垂支撑。保护2mm侧翼和槽底薄壁，清支撑并修铰孔至滑动配合。无打印机配置、切片、G-code或实物样件，不宣称实际紧配手感。
前后板四方孔向下套住底板对应方桩；不得用锤击强装。没有底M3螺钉，勿按旧说明钻孔或拧螺丝。侧板仍从上插入，不装侧面M3。此为几何试装，未解决防拔前不要通过挂环提包，不要靠磁铁把松配组件当承载结构。后续固定方式会影响可拆维护，胶粘、卡扣等需另外确定，不在本版暗中增加。
装挂环：钢垫板贴侧板内面，以7mm扳手托住M4螺母；外放隔套、挂环、止推片，将M4×15手拧螺丝向内拧紧。夹隔套而环可转，不靠松螺丝取得转动。内螺母/钢板无定位口袋，拆时接住，内伸端去毛刺。金属M4用可拆卸防松措施，避开PETG并做位置标记；扭矩和0.3mm环旁间隙待实测。
磁铁先核对极性，清洁后胶粘入小圆槽；具体胶种未选，先验证PETG与镀层相容性、固化保持力和防脱。不得用未经验证的装饰胶代替磁铁防脱胶。没有机械盖片，松脱或破损磁铁应停止使用并取出，避免遗失小件。
铰轴一端预成头，闭盖对齐铰孔，留左侧直线空间，穿轴后形成第二铆头；用金属工装支承轴头，不将锤力压到PETG铰筒，不以热塑料代替金属铆接。保持两端各1mm轴向余隙和自由转动。CAD显示最终双头，不可采购双头成形轴硬穿孔。拆盖需磨/钻除一头并换轴，属破坏性维护；侧板维护不拆轴。铆接夹具及成形工艺需实作验证。
普通开盖无需解带或拆环。干装侧板维护：卸载并托住底板，拆手拧螺丝、环、隔套、外垫片、内M4螺母/钢板，开100°后上抽，勿强压薄板。金属环及金属扣舌边去毛刺、倒圆，不以普通FDM替代金属而宣称同等负载。扣舌与框是一体曲面定制件，外观需要成形匹配，不是普通平板直接贴合的厂家扣。
贴面带、标线及扣框仅非承力装饰，PETG相容薄胶先试样片、顺弧贴合；不跨开口做刚性闭环。永久粘下U带会连接前/底/后板，拆板前先拆装饰带，不强拉；该装饰粘接不作为结构补救。
新顶带3mm实体隆起需要成形/单独打印形状，不可用1mm等厚平带直接贴出该形状；底面照旧贴合。新凸起扣舌应倒钝金属自由端、防勾衣，凸起不是锁定扣合，也不可用它提包。0.4mm外轮廓倒角无需给页槽和孔口额外磨削，避免伤配合。
无螺丝防拔方式解决后，再以2kg内容物加自重进行单环偏载、双倍总重1小时、1000次提携/开合；检查方桩根、方孔连接台、侧板保持处、环孔、蠕变、M4松动、侧翼、铆头、扣舌边缘及装饰脱落、磁铁胶粘和0.8mm面隙磁力。当前不可略过保持方式直接做提携宣称。遮尘及小物保持待实测，0.6mm弧缝非防水密封，不承诺防水。
