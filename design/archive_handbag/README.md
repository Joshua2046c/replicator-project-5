# 三层书本造型手提包

依据 product/references/uploads/20260923T155951796Z-1-mark.png 及用户澄清：220宽×120深×190高mm主包，不含外凸连接环组件与用户肩带；内容物目标2kg、自重另计。粉/蓝/绿三叠书，弧形书脊，整块矩形书页侧板，中央棕色束带绕前顶背底，后背与盖背齐平且有对应书页槽。无整体内胆，仅外板拼装。当前闭合CAD build124。

## 接口与设计
- 七个主要打印外板：后承力板body、bottom_panel、green_spine、blue_spine、lid和两个矩形侧板。底板厚4，后板厚6，弧形前板厚3.5；底部8颗M3×12沉头螺钉，蓝/绿前板4颗M3×12。磁铁座与蓝板一体，不靠胶粘承重。后角遮盖小台面为后外板一体特征，不是内胆。
- sliding_panels：每块3×100×182.4，X±107.5，底Z4、顶Z186.4；3.6槽，每面0.3余隙；闭合盖底Z186.8限制上移。顶部金属支架及后角遮盖上有3.6mm通过槽，开盖后仍能直线上抽。不作水密承诺。
- curved_spines：绿高60、蓝高64、盖弧高60.4，弓高6。粉色弧形前缘与翻盖整体，非贴上去的平片。标线单独薄片固定。
- lid_hinge：轴心Y55 Z128，X向Ø4×100光轴，孔Ø4.4，铰筒半径3.8，轴端各0.4间隙；两端kit生成M3×10止挡。齐平背面Y57，后缘有开合倒角。后/侧纹路6mm节距，分界Z64/128；上盖后面的页纹与侧板同高。
- magnet_closure：X±72、Y−39；4颗Ø7×3轴向磁铁，底板侧磁铁底Z124.2、盖侧Z129.4，面间距2.2。防脱盖22×14、边厚2.6、膜0.6，8颗kit M2×6，实际吸力尚未实测。
- carry_rings：顶部固定孔X±97 Y49；定制304支架将转环轴心外移31至X±128。原M4×20固定支架，另M4×12为转环轴。支架47×18×2、后折防转舌5，金属桥上侧板通过槽保留7.7宽连接。环由3mm竖向片28×32和2mm底脚18×18焊接；穿带孔14×24，底脚孔6.4。Ø6/Ø4.3×2.6钢隔套支撑1.4mm止推垫片，环2mm厚，轴向总余隙0.6。外侧M4滚花小帽Ø10×4锁紧隔套，不能拧松螺帽来实现旋转。共4颗小帽含两个支架固定帽。环组件从顶部承力，不装在可拆侧板上，不通过磁铁传载荷。
- 主包外廓220×120×190；当前姿态含外凸环组件274×122.2×224.3。转环旋转时最大外廓会变化，不将含环尺寸误称220宽。金属外伸是避开盖扫掠的设计默认。
- strap_route：中央棕色30×1柔性包络绕前/顶/背/底；前Z100有释放口，方框下28×28可剥离搭接，上半缝合、下半hook-and-loop。方框作为可拉取装饰件，释放并移开束带后开盖。不打印闭合刚性环，不包括用户肩带。

## 几何真实性及验证
M4×20、M4×12来自验证目录bd-warehouse的不可变ISO4762 STEP。其余打印螺钉由printed-screw-joint-v1生成。底板沉头套件有约0.1mm头缘干涉，已用套件自身返回的螺钉包络修正底板座，不是手绘塑料螺纹。环、支架、垫片、隔套、滚花帽为本项目定制金属件；螺帽模型为名义M4螺纹包络，不是攻丝底孔。磁铁为尺寸包络，不声称厂家STEP。

build124：闭合装配未报告干涉；verification/motion-check.json共11550组B-rep配对检查，开盖0–100°每5°、移开束带后无碰撞；开100°后侧板多个抽出高度无碰撞，闭盖提升1mm会被顶盖挡住。verification/swivel-check.json共3216组配对，环每15°旋转采样无碰撞；环径向包络与盖最外侧X边界至少1.3567mm，因此环全向旋转不侵入盖的X扫掠范围。这些是离散/几何检查，不是负载、疲劳、防松或磁力认证。

## Making and assembly
原型PETG，建议0.2mm层高。底板平放，侧板大面平放；弧形前板、后板和盖按外观面与受力方向选择摆放及支撑，先做导槽、轴孔配合小样。后角薄台面、盖铰筒与磁铁座悬垂需支撑；移除支撑后检查0.6mm磁铁薄膜，孔后铰到滑动配合。未配置打印机、切片或G-code。
先把蓝/绿前板螺接，再将前板和后板各用4颗底部螺钉固定到底板。M3/M2塑料成形螺纹轻拧到位，不反复拆装；不要让底部螺钉突出刮桌。插入两块侧板；核对磁铁极性，装磁铁和防脱盖；装翻盖、金属轴和轴端止挡。上部转环支架、内垫板和外置帽从内外两侧装配；支架上的槽须对准侧板通过位置。
金属环的3mm竖片与2mm脚板为焊接结构，不是假定单厚度折弯件。支架和环切边去毛刺、穿带孔倒圆；焊缝、开槽金属桥、打印承力后柱必须样机检验。不得用普通FDM复制金属环宣称相同承重。紧固金属M4螺纹采用可拆卸防松措施，避免防松材料接触PETG，并做螺帽位置标记；隔套必须夹紧而环能转，不能靠松螺帽转动。手拧帽直径小，装配扭矩与塑料蠕变尚未验证。
最后安装金色标线和柔性棕色束带；非承力装饰可用PETG相容胶薄层固定。与旧版不同，本版是完整环绕柔性带，不再是跨开合缝的分段硬装饰；开盖前拉开方框下搭接并移开带体。卸载后打开盖，侧板沿顶部通过槽上抽维修，不强压薄板。
尚无实体样件，不能报告实际哪里紧或实际拆装手感；先做公差小样，卡滞时修整导槽。2kg为内容物设计目标，试验需加包体自重：单环偏载、双倍总重1小时、1000次提携与1000次开合，检查焊缝、金属桥、外板螺接、后柱裂纹/蠕变、螺帽松动及磁吸保持力。普通遮尘/防掉物也需实测，不承诺防水。
