# 三层书本造型手提包

当前build270，依据本轮用户文字：页槽等距、封面封底留带、统一书脊曲率、底缘无台阶、左右小圆磁铁槽、后轴可实际侧向插入。此前直接翻盖和侧板前上角圆弧避让保持。

## 用户要求与当前结构
蓝绿两本书脊是一块完整前板，前后板插底板；侧面书页板自上滑入，非T形，上前角圆弧避让；上盖两端与盖一体。棕色带贴面嵌槽，在开口和转轴断开，扣框中心方块取消。没有内胆，整幅齐平盖背及侧面顶部挂环保持，用户自装肩带。
原用户标称包络220×120×190mm，不含突出挂环及肩带；2kg内容物目标，自重另计。当前主包含铰链220×122.3×190mm，含当前姿态五金238×122.3×210mm。外凸铰链导致总深度多2.3mm。用户在单项尺寸裁决中答复“这部分不改了”：**保留本版外凸铰链，接受122.3mm深度例外，原120mm标称要求保留；不宣称本版精确120mm深度。** 无其他未决要求。

## Making and assembly
原型PETG，建议0.2mm层高。先做底舌/槽、铰孔、0.6mm圆弧缝、AF7.4螺母口袋、磁铁圆槽及贴带凹槽样片。底板平放、侧板大面平放；前板、后板和盖按外观/受力方向选支撑。盖铰筒、小磁铁座、L臂及垫板/螺母口袋悬垂需支撑评估；承力臂优先平面平放，避免主载荷跨层。保护侧翼2mm及槽底薄壁，清除支撑并修铰孔至滑动配合。无打印机、切片或G-code配置，无实体样件，不能报告实际紧配或手感。
前后板插底槽，8颗底面M3轻拧防脱，不再拼接蓝绿板。M3塑料成形螺纹避免反复拆装；底螺钉不得突出。盖安装前从上插侧板，内钢垫板和M4螺母放固定L臂口袋；外侧放隔套、挂环及止推片，将一体手拧螺丝向内拧入螺母。夹紧隔套但环仍可转，不能拧松螺丝获得转动。螺母卸载后不保证留在口袋，拆装时接住，内伸螺丝端去毛刺。
磁铁先核对极性，清洁后胶粘入小圆槽；具体胶种未选，先验证PETG与磁铁镀层相容性、固化后保持力及防脱，不能用装饰胶未经验证代替磁铁防脱胶。没有机械盖片，破损或松脱磁铁应停止使用并取出，避免遗失小件。
铰轴一端预成头，闭盖对齐铰孔，预留左侧直线装入空间，穿过铰节后再形成第二端铆头。成形时用金属工装支承轴头，不将锤击力压在PETG铰筒上，不以加热塑料代替金属铆接。保持各1mm轴向余隙及自由转动。CAD导出显示最终双头状态，不可采购双头已成形轴后强穿孔。拆盖需磨除/钻除一端铆头并更换轴，属破坏性维护；侧板维护无需拆轴。铆接夹具与具体成形工艺尚待实际制作确认。
普通开盖无需解带或拆环；维护先卸载，拧出手拧螺丝及外五金，开100°后上抽侧板，勿强压薄板。金属环切边去毛刺、孔边倒圆，不用普通FDM件替代金属而宣称同等负载。金属M4用可拆卸防松措施，避免耗材接触PETG，并做位置标记；扭矩、L臂蠕变及环旁0.3mm余隙待实测。
贴面带及标线仅非承力装饰，用PETG相容薄胶先做样片，顺弧贴合；不打印成跨开口刚性闭环。前开口和转轴处分段，不需魔术贴搭接或拉框解带。永久粘贴下U形带会连接前板、底板和后板，拆板前先拆装饰带，不能强拉。
实体负载试验以2kg内容物加自重：单环偏载、双倍总重1小时、1000次提携及1000次开合，检查L臂根、环孔、底舌和螺接、侧翼、手拧螺丝松动、铰轴铆头、装饰脱落及0.8mm面隙磁力与磁铁胶粘防脱。遮尘和防小物掉出待实测，0.6mm弧缝非防水密封，不承诺防水。
