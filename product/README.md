# 三层书本造型手提包

依据本次 `references/uploads/20260924T022138858Z-1-mark.png` 和用户文字修改。当前build193是闭合外观与插接修订模型，**开盖干涉尚未解决，不是可直接制造使用的完成版**。

## 本轮要求与实现
- 蓝绿两本书脊为一块完整弧形前板：CAD只有一个实体；分色通过打印配色或涂装，不通过上下分件螺接。
- 前书脊板与后板插入底板定位槽；每板两条70mm长插舌，插深约2.2mm，底槽2.4mm深、每侧0.3mm余隙。默认保留底部原8颗隐藏螺钉防止提携时拔脱；取消蓝绿拼接的4颗螺钉。
- 两侧保持完整矩形书页板，自上方沿滑槽插入。上端挂环位置及金属五金不改。
- 上盖左右小条已经并入整幅盖体，不再属于固定前板。
- 棕色装饰带30mm宽、1mm厚，贴合并嵌入前顶背底轮廓；在前开口Z128–128.6以及后转轴Z123.5–134断开，开盖不必解带。扣外框保留并贴合曲面，中心方块已取消。

## 当前阻塞项
现有固定后轴Y55 Z128搭配一体盖端，会在开盖5°、15°、30°碰到矩形侧板前上角；15°时左右各约477.076mm³实体相交。不能用闭合时无碰撞代替开盖通过。
用户此前要求完整矩形侧板，因此未擅自削掉上前角；需要选择接受先抬升再翻开的开启动作，或允许侧板前上角作弧形避让来保持直接翻开。两种方向均需后续建模验证，尚未宣称可用；若仅保留外观，必须明确记录开盖例外。

## 已做的检查
闭合装配未报告实体干涉；前后板对底板的6个插接高度检查无穿透；绑带与对应凹槽、扣框与曲面距离0且实体相交体积0。挂环每15°旋转共2496配对无碰撞。开盖6个采样角共2772配对发现6处侧板干涉。100°姿态的抽板检查仅为姿态检查，该角度目前无法从闭合无碰撞到达。
标称包络要求仍为220×120×190mm；去掉悬空凸出的绑带后本模型实际主包边界220×116.8×189mm，含当前姿态五金240×116.8×210mm。没有修改用户尺寸要求来宣称符合。

## 保持的边界
2kg内容物目标、自重另计；四颗Ø7×3磁铁、一般遮尘及防掉物、无防水承诺；用户自行装肩带。原型PETG，金属五金不可用普通FDM等同替代。负载、磁力、打印公差、防松、寿命未实体测试。当前STEP用于检查修订外观和定位插接，不含切片、G-code或可用开盖认证。
