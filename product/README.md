# 三层书本造型手提包

当前修改模型为build270。依据本轮文字要求：侧面页槽等距、每本上下留封面/封底厚度带、三段书脊统一曲率、底部圆弧无台阶、左右小圆磁铁槽、后轴可从侧面插入。

## 本轮实现
- 每本9条页槽、6mm等距；页块浅退0.25mm，槽在页块基础上再深0.45mm、宽1mm；上下4mm留带。侧板、后板、上盖背面与侧翼使用对应槽高。以上具体数值是设计默认值。
- 三段书脊及最下方底板前缘统一R88.333333mm。下两本高度均64mm，上盖前书脊从Z128.6到190。蓝绿前板仍为一整块。
- 磁铁保持左右各一对Ø7×3，共4颗。圆座Ø11.3×5.4、圆槽Ø7.3深3.2，X±72/Y−45.8；取消4个盖片及8颗磁铁座螺钉。名义磁铁面隙0.8mm；改胶粘防脱，槽口最薄外侧材料1.55mm。胶种与防脱效果需样片验证。
- 后轴心Y60.5/Z128，比上版后移2.3mm；轴心位于背面外3.5mm。Ø4×100轴、Ø4.4孔，预成一端Ø6×1.4头，穿轴后另一端成形。没有后轴止挡螺钉及矩形孔。CAD装配检查使用单端预成头状态，非把已成形双头轴硬穿入孔。

## 保留的结构
无内胆；蓝绿一体前板和后板插底槽、8颗底部隐藏M3螺钉防脱；侧板自上滑入且前上角圆弧避让；上盖端部一体；前顶背底贴面分段装饰带、空心扣框；侧面金属挂环及外侧一体M4×20手拧螺丝，内侧标准M4螺母装在固定承力臂，而非锁死活动盖。用户自行安装肩带。2kg内容物加自重、普通遮尘和防掉物目标不变。

## 检查结果与尺寸例外
build270：37对象40实体全部有效；闭合666对筛查、72对精确交集运算，零碰撞；0–100°每5°共3360对开盖检查无碰撞；拆手拧螺丝及外五金后两侧板11个抽出位置无碰撞；挂环每15°共1728对检查无碰撞。贴带/扣框接触及底部插接检查通过。三段外弧及底缘B-rep半径一致，底板接缝点连续。
单端预成头轴由左向右插入160mm行程的圆柱解析连续扫掠无碰撞，最小间隙0.2mm；预成头与平背面间隙0.5mm。该结论不包含铆接工具、打印误差或实际装配手感。

**尚有一项尺寸冲突：原用户包络220×120×190mm（仅排除挂环和背带）保持不变；当前含外凸铰链为220×122.3×190mm，总深度多2.3mm。用户答复“这部分不改了”，本版保留当前后轴并接受该2.3mm例外；不是精确120mm总深度。** 当前姿态连挂环五金为238×122.3×210mm。
