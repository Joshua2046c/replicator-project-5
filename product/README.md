新增封面22.222×60×0.9mm、R3圆角空白铭牌，内嵌1mm盲槽且顶面齐平，槽底剩1.2mm；书脊六件饰块向内嵌入1.1mm、槽深1.2mm。两者侧边0.15mm、底0.1mm薄胶留量，不是自锁卡扣。尺寸是可修改的默认值。

## 使用限制
2kg内容物加自重目标保持。**本版干装不能作为可承重成品**：直插方桩与可抽侧板缺少可靠防拔连接；装饰带、扣舌、顶部隆起及磁吸均不能替代承重锁定。本次不擅自加回螺钉或指定永久胶粘。模型可用于外观与接口试装。
