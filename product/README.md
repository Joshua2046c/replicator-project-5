# 三层书本造型手提包

本轮依据 `references/uploads/20260924T033939842Z-1-mark.png` 和用户文字修改，当前build226。

## 本轮要求与实现
- 上盖页槽延续到Z182mm，背面、两侧书页和一体圆弧侧翼对应；槽深0.45、宽1、节距6mm。
- 后铰轴向后外移3.2mm至Y58.2 Z128，轴心已在背面Y57以外。取消两颗止挡螺钉和两块止挡，原矩形空洞填补，仅保留必要圆轴运动余隙。
- Ø4×100定制金属轴采用两端Ø6×1.4铆头防脱：一端预制，穿轴后另一端成形。拆轴维护需处理铆头，不能像旧版拆螺钉止挡。
- 外侧两颗M4×20手拧螺丝各为一个完整实体，头Ø10×4；盖下内侧装标准ISO4032 M4螺母。螺母在固定承力臂内，未把活动翻盖与侧板锁死；仍不靠磁吸承重。螺纹用名义金属包络表示，不是FDM打印螺丝。

## 保留的结构
蓝绿一体弧形前板、前后板插接底板及8颗隐藏底螺钉、4mm侧板从上滑入、前上角圆弧避让、一体上盖端部、前顶背底贴面分段装饰带与空心扣框均保留。用户自行安装肩带，无内胆。

## 几何检查与边界
build226：49对象52实体，1176对闭合筛查、103对精确B-rep运算，零碰撞；0–100°每5°共8778配对无开盖碰撞；挂环每15°旋转2304配对无碰撞。拆手拧螺丝及外五金后，两侧板11个上抽位置无碰撞。每颗手拧螺丝为单一实体，螺母/钢垫板和手拧头/止推片接触无穿透。铆轴往左右移动1.2mm均被固定铰节阻挡。
当前主包含铰链220×120×189mm，含当前姿态挂环五金238×120×210mm。原标称220×120×190mm未改，当前高度仍低1mm，不宣称精确等于标称。
2kg内容物加自重、四颗Ø7×3磁铁、一般遮尘与防掉物目标保持。几何采样不是连续扫掠、承载、蠕变、磁力、防松或寿命认证；须打样实测。不含切片、G-code和实体测试。
