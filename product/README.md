# 三层书本造型手提包

当前以build315为基准，左侧按右侧完整几何镜像重建：书页槽、圆弧端部、挂环孔和下插配合边统一。此修改不引入45°拼接。

继承的build315结构：
- 金属扣舌改到方框底边中央，向上伸约半框高度，并向外凸起；不再从左侧横伸。默认长22、宽5、厚1mm，末端比原框面高2mm，与框单实体连接。
- 顶带只有本次标出的端头平面轮廓做半圆R15，其余凸起横向平直，不做圆拱。默认宽30高3mm，向前至Y−40渐变收低，仍非提手。
- 依据图中红框，将“背板”解释为侧面书页板：下两层半圆区域并入左右侧页板，消除原Y−50直缝；页块凹陷及每层9条页槽延至书脊弧边。两侧各一个完整实体，与前书脊板0.3mm横向间隙，上层翻盖避让保持。
- 主体十二条大边区域做默认0.4mm小倒角：顶四边、底四边、前两条随弧竖边、后两条竖边。细书页槽边及孔、插接配合面不做全面倒角。
- 保留八个4×4×6底方桩及4.4方孔，取消底螺钉、侧面小锁栓及长定位槽的要求不变。三书脊共同R88.333333；蓝绿一体前板、无内胆、直接翻盖、挂环五金及四颗Ø7×3磁铁保持。

新增封面20×36×0.9mm空白铭牌，内嵌1mm盲槽且顶面齐平，槽底剩1.2mm；书脊六件饰块向内嵌入1.1mm、槽深1.2mm。两者侧边0.15mm、底0.1mm薄胶留量，不是自锁卡扣。尺寸是可修改的默认值。

## 使用限制
2kg内容物加自重目标保持。**本版干装不能作为可承重成品**：直插方桩与可抽侧板缺少可靠防拔连接；装饰带、扣舌、顶部隆起及磁吸均不能替代承重锁定。本次不擅自加回螺钉或指定永久胶粘。模型可用于外观与接口试装。

## 检查与尺寸
build315：30对象、33有效实体；闭合435对筛查、50对精确交集，零干涉。开盖0–100°每5°共3024对、挂环每15°共1392对无碰撞；拆挂环五金后左右侧板各11抽出位置无碰撞。方桩/孔、十二大边探测、顶带渐变高度和底边凸起扣舌检查通过。磁铁、书页槽、同弧及铰轴连续插入检查通过。不是实物承重、胶粘或密封测试。
原包体标称220×120×190mm保留，原外凸铰链122.3mm深度例外已由用户接受；本轮明确要求的装饰凸起另占空间。含扣舌、顶带及铰链、不含挂环约220×124.237×193mm；当前姿态含五金238×124.237×210mm。隆起尺寸是可调默认值，不将新增外凸误称为仍在190mm高度以内。
