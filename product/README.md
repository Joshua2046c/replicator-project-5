# 三层书本造型手提包 — 当前需求与交付

## 当前依据
以 `references/uploads/20260923T202609989Z-1-mark.png` 及本次说明为准：挂环在侧面顶部红框位置；侧板、背板装配外沿与盖齐平；三层书脊侧面一致；去除顶底盖多出的凸边。

## 保持的要求
主包220×120×190mm，不含突出挂环及用户背带；内容物2kg、自重另计。粉色翻盖、蓝绿外板拼装，无整壳内胆；左右完整矩形插板，弧形书脊，贯穿转角的横向页槽，整幅齐平盖背。内置4颗Ø7×3磁铁并机械防脱。中央棕色柔性带绕前顶背底，开盖前释放移开；用户自行装肩带。一般遮尘、防小物掉出，不要求防水。

## 当前实施默认
- 挂环上移并前移至侧面上端Y0 Z174，保留转动和外置小手拧帽；固定内臂连到后外板承载，不靠磁吸。
- 侧板4mm厚，外面X±110与盖、背板齐边；抽板维护需先卸载并拆挂环螺栓。普通开盖不用拆环。
- 三层书脊外观宽220、弓高6；顶层两条4.3mm窄端边固定并与蓝板一体，表面涂粉色，中部随盖转动，避免扫到完整侧板。这是结构分件缝，不是高低台阶。
- 顶底板前沿收至Y−51，与书脊端部齐平；仍保留必需的屋面2.2mm和底板4mm厚度，不再外伸成凸檐。
- PETG原型；金属环、轴、隔套和五金不能用普通FDM替代后宣称同等承载。

## 检查与边界
build184已通过0–100°每5°开盖采样、卸去挂环通栓后的11个抽板位置、每15°挂环旋转采样；闭合装配未报告干涉。主包220×120×190，含当前姿态五金240×120×210mm。交付为分件STEP及当前预览；独立审查以导出记录为准，不含切片或G-code。
2kg负载、侧臂蠕变、窄端边耐用性、0.3mm配合、防松及实际2.2mm磁铁气隙保持力未做实体试验。建议配合小样，再含自重单环偏载、双倍总重1小时、1000次提携及1000次开合；不是承重认证。
