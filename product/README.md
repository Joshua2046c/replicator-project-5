# 三层书本造型手提包

当前修改模型build297，按最新标注完成：
- 删除左右侧板中部锁栓、螺母及对应通孔/沉孔，保留原挂环M4连接件。
- 八个底部螺钉点位改为底板一体正方形插桩；前后板各四方孔。取消前后板长条插舌和底板长定位槽，不再有底部螺丝。
- 默认方桩4×4×6mm，方孔4.4×4.4、深6.3mm，顶边0.4mm导入倒角；前后排Y−47/52、X±40/±80。每侧0.2mm余隙，属于试装配合，不是抗拔锁扣。
- 三本正面外弧保持共同R88.333333mm。下两段端部内缘由方直轮廓改为随弧轮廓，侧板导向保留；底缘仍连续圆弧。
- 金属方扣由左框伸出半截金属舌至中心，默认名义长22、宽5、厚1mm，与整个扣框为单实体；不恢复中心方块，不增加活动锁扣功能。

## 使用限制
2kg内容物加自重目标保持，**本版干装不能视为可承重手提包**。去掉底部和侧面锁定后，直插方桩与滑入侧板均缺少可靠防拔脱连接；磁吸和装饰带不能替代承重锁定。无螺丝保持方式尚待确定及实测，本次不擅自加回螺钉、卡扣或强制永久胶粘。当前模型适合外观及接口试装检查。

## 保留的结构
无内胆，蓝绿一体前板、直接翻盖、侧板前上角圆弧避让、上盖一体端翼、分段贴面装饰带、四颗Ø7×3磁铁小圆槽、侧面金属转环、M4×15一体手拧螺丝及贴侧板钢垫板/螺母。用户自装肩带。

## 检查与尺寸
build297：29对象、32有效实体，闭合406对筛查/52对精确交集，零干涉。开盖0–100°每5°共2520对、挂环每15°共1344对无碰撞；拆挂环五金后两侧板各11个抽出位置无碰撞。方桩/孔、长槽取消、侧锁孔填平、扣舌单实体检查通过。三段外弧及底缘同半径，底缘连续；单端预成头轴连续插入检查最小间隙0.2mm。检查不包含物理承重或胶粘效果。
