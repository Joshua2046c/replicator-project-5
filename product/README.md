# 三层书本造型手提包 — 产品需求

## 当前造型依据
以本次标注图 `references/uploads/20260923T155951796Z-1-mark.png` 和用户随图说明为结构修订依据。此前图片继续提供粉、蓝、绿三层书本、棕色束带和方扣的造型依据；本次明确要求优先于旧版CAD实现。图片没有可靠尺寸标尺，不据此推导螺帽尺寸。

## 已确定的要求
- 主包外廓220宽×120深×190高mm，不含外凸连接环及用户自装肩带；内容物载荷目标2kg，包体自重另计。
- 最上层粉色书本通过转轴翻开，内置Ø7×3mm磁铁吸合。默认仍为前缘两对、共4颗磁铁，需机械防脱。
- 左右每侧各一块覆盖三层全高的完整长方形插板，自上向下插入，不能是下段收窄的T形。
- 不需要完整内衬或内胆，整个包由外板块组合。
- 书脊具有弧度，不能使用平面装饰板代替。
- 左右独立背带环位于顶部，不在侧面；采用螺栓固定，小型手拧螺帽位于外侧，环能够转动。
- 盖子背板外表面与包本体背面齐平。
- 背面也有书页凹槽，三层分界和槽高与侧面书页对应。
- 用户要求“背带是贯穿的”；具体所指的带及路线见下方唯一待澄清项。
- 合缝、防小物掉出和一般遮尘，不要求防水，不宣称IP等级。

## 唯一待澄清的产品问题
“背带贯穿”是指中央带方扣的棕色束带绕过顶部、背面和底部，还是指用户自装的肩带穿过包体？这个答案决定背板/底板的带槽及翻盖连接方式。此前“只留拉环孔，我自行安装背带”的要求保持不变，不能在没有澄清时擅自增加肩带本体。

## 设计默认及后续实施责任
- 原型采用PETG分件FDM；承重环、转轴及必要的承力五金为金属，不承诺全打印同等承重。
- 保持贯通收纳空间，目标开盖至少100°。矩形侧板采用边缘导向、底部止挡和合盖限位；顶部环的支座不应阻挡侧板拆卸。
- 顶部转环载荷应经固定外板连接传到底板，不得仅靠磁铁保持盖子来承担提携载荷。
- 转环轴肩或隔套、旋转间隙、小手拧螺帽防脱、外板拼接及铰链重排属于本次硬件/CAD实施责任，不要求用户指定螺钉长度或孔径。
- 旧版双螺栓侧置环、六角螺母、T形导槽和完整内壳接口不能继续作为新版依据。BOM和约束表已明确标记待重定型，不用于采购。

## 验收计划
1. 外观检查矩形侧板、三段弧形书脊、顶部转环、齐平背板，以及侧后书页槽的对应关系。
2. 检查所有外板的连接、闭合干涉、开盖运动、侧板抽出、转环转动与外侧螺帽手指操作空间。
3. 在新版磁铁实际安装间隙下测保持力和开启手感，确认磁铁无松脱。
4. 默认样机计划：含包体自重的单环偏载、双倍总重静载1小时、1000次额定载荷提携及1000次开合；这些均尚未进行，不是强度认证。
5. FDM导轨、轴孔和薄壁先做配合试样；不作防水承诺。

## 交付与当前状态
目标仍为修订后的完整分件装配STEP及当前预览，不含切片、G-code或实体测试。当前几何和导出仍为build41，尚未修改；该版本的审查与运动检查只对应旧结构，不能用来证明本次修订。需求及BOM正在等待上述一项产品澄清，随后重新设计并导出。
