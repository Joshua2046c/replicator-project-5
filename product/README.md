# 三层书本造型手提包

依据本次 `references/uploads/20260924T022138858Z-1-mark.png` 和用户文字修改。当前build196已按用户确认的圆弧避让修复开盖路径；CAD检查通过，实体负载与打印配合尚未测试。

## 本轮要求与实现
- 蓝绿两本书脊为一块完整弧形前板：CAD只有一个实体；分色通过打印配色或涂装，不通过上下分件螺接。
- 前书脊板与后板插入底板定位槽；每板两条70mm长插舌，插深约2.2mm，底槽2.4mm深、每侧0.3mm余隙。默认保留底部原8颗隐藏螺钉防止提携时拔脱；取消蓝绿拼接的4颗螺钉。
- 两侧书页板自上方沿滑槽插入；按用户本轮确认，前上角改为圆弧避让。上端挂环位置及金属五金不改。
- 上盖左右小条已经并入整幅盖体，不再属于固定前板。
- 棕色装饰带30mm宽、1mm厚，贴合并嵌入前顶背底轮廓；在前开口Z128–128.6以及后转轴Z123.5–134断开，开盖不必解带。扣外框保留并贴合曲面，中心方块已取消。

## 开盖修复与检查
用户选择保留直接翻盖、允许侧板前上角作弧形避让。侧板圆弧半径103.4mm与盖侧翼内圆弧104mm同心于原转轴，名义间隙0.6mm；盖侧翼与盖一体，覆盖避让区域并延续页纹。
闭合53对象1378配对筛查、109个有包围盒交集的精确运算，无实体重叠。0–100°每5°开盖共9702配对无碰撞，装饰带留在包上；卸载并拆挂环通栓后，侧板11个上抽位置无碰撞。挂环每15°旋转共2496配对无碰撞。前后板6个插接高度无穿透；贴面装饰与对应表面距离0、相交体积0。这些是几何采样，不是连续扫掠、承重或寿命认证。

标称包络要求仍为220×120×190mm；去掉悬空凸出的绑带后本模型实际主包边界220×116.8×189mm，含当前姿态五金240×116.8×210mm。没有修改用户尺寸要求来宣称符合。

## 保持的边界
2kg内容物目标、自重另计；四颗Ø7×3磁铁、一般遮尘及防掉物、无防水承诺；用户自行装肩带。原型PETG，金属五金不可用普通FDM等同替代。负载、磁力、打印公差、防松、寿命未实体测试。当前STEP包含上述修订与开盖修复；不含切片、G-code或实体测试认证。
